# 2. Game Design

## Паспорт игры

| | |
|---|---|
| Рабочее название | UMBRA (Expedition D-05) |
| Жанр | Cinematic 3D Adventure + Exploration + Survival + Stealth + Light Horror |
| Камера | Третье лицо из-за плеча; первое лицо в режимах фотокамеры, сканера и в кабине вертолёта |
| Платформа | PC (первично), консоли текущего поколения — позже |
| Движок | Unity 6, HDRP — обоснование в [roadmap](09-roadmap.md) |
| Длительность | 9–11 часов основной сюжет, 15–18 часов на 100% журнала |
| Главное ощущение | «Я участвую в настоящей экспедиции на неизвестный остров, где живёт настоящая доисторическая экосистема» |

## Четыре столпа

Всё, что не поддерживает хотя бы один столп, из игры вырезается.

1. **Остров живёт без игрока.** Животные едят, спят, охотятся и мигрируют,
   даже когда на них никто не смотрит. Игрок — гость, а не центр мира.
2. **Смотреть, а не стрелять.** Знание сильнее оружия. Кто понял поведение
   вида, тот его и обошёл.
3. **Кино без отнятого управления.** Постановка работает через то, куда игрок
   сам смотрит и куда идёт, а не через экран «смотри ролик».
4. **Тайна раскрывается через мир.** Документы, следы и забаррикадированные
   двери рассказывают больше, чем диалоги.

## Игровые циклы

### Микроцикл — одна встреча (2–10 минут)

```
ЗАМЕТИТЬ СЛЕД → ПРОЧИТАТЬ (вид, свежесть, направление) → ИДТИ ПО СЛЕДУ
      → УВИДЕТЬ ЖИВОТНОЕ → НАБЛЮДАТЬ / ФОТОГРАФИРОВАТЬ → РЕШИТЬ: обойти, ждать, действовать
```

### Средний цикл — одна глава (40–90 минут)

```
ИССЛЕДОВАНИЕ → ОБНАРУЖЕНИЕ СЛЕДОВ → ПОИСК ДИНОЗАВРА → НАБЛЮДЕНИЕ → ОПАСНОСТЬ
      → ПОЛУЧЕНИЕ ДНК → ВОЗВРАЩЕНИЕ В ЛАГЕРЬ / ПЕРЕМЕЩЕНИЕ → НОВАЯ ОБЛАСТЬ
```

### Метацикл — вся игра

```
ДНК 0/5 ─► 5/5          (официальная цель)
Журнал 0% ─► 100%       (понимание острова)
Тайна: слой 1 ─► 3      (понимание, зачем всё это)
```

Три шкалы растут с разной скоростью. Когда одна стоит, растёт другая — так
закрыт провал темпа из [анализа](01-analysis.md#3-провал-темпа-между-днк-4-и-днк-5).

## Системы

### 2.1. Сбор ДНК

**Оборудование** (лист ассетов, блок 12):

- **Кейс** — защищённый кейс с **шестью** гнёздами. В пять вставлены
  контейнеры, шестое закрыто заглушкой «N/A». Это зацепка тайны.
- **Контейнер** — капсула для живых клеток с индикатором.
- **Набор для образцов**: тампоны, пинцет, скальпель для соскоба.
- **Биопсийный арбалет** — с Акта IV.
- **Сканер** — планшет, проверяет качество образца.

**Состояния контейнера** — они же UI:

```
EMPTY → SAMPLE LOADED → SEALED → ANALYZING (4–6 с) → VERIFIED ✓
                                                  └─► REJECTED ✗ → контейнер очищается, снова EMPTY
```

**Правило живых клеток.** `VERIFIED` получает только образец с живыми клетками:
свежая кровь, кровяное перо, биопсия, мембрана только что вылупившегося
детёныша. Кость, старая кровь, образец из туши и замороженные лабораторные
пробы дают `REJECTED — NO VIABLE CELLS`.

**Кейс на рюкзаке.** В третьем лице кейс висит на рюкзаке Итана, на его крышке
пять огоньков: серый — пусто, зелёный — подтверждено. Это основной счётчик ДНК.
Всплывающая надпись `DNA COLLECTION: 2/5` появляется только в момент изменения.

**Типы образцов:**

| Образец | Откуда | Срок годности вне контейнера | Где используется |
|---|---|---|---|
| Свежая кровь (мазок) | Раны, кровь на растениях | 10 мин игрового времени | ДНК 1 |
| Кровяное перо | Растущее перо с кровотоком (у рапторов есть остатки перьев) | 5 мин | ДНК 2 |
| Биопсия | Дротик в мягкую кожу с 10–25 м | Дротик держит образец живым, пока плавает | ДНК 3 |
| Мембрана / царапина детёныша | Гнездо, птенец | 10 мин | ДНК 4 |
| Станционная проба | Биопсийный захват станции Варна | Капсула станции | ДНК 5 |

Срок годности — мягкое правило: за образцом не надо бежать с таймером на
экране. Если игрок протянет слишком долго, анализ покажет `REJECTED` и
объяснит почему.

### 2.2. Следы (система следопыта)

Итан — бывший рейнджер, двенадцать лет выслеживал браконьеров. Игра строится на
его навыке.

**Типы следов:**

| След | Что сообщает | Как выглядит |
|---|---|---|
| Отпечаток лапы | Вид, размер, скорость (по шагу), направление | Декаль в грунте, глубина = вес |
| Сломанные ветки | Высота животного, направление | Сломанная геометрия и свежий сок |
| Помёт | Вид, свежесть, чем питался | Модель с частицами мух (мухи = свежий) |
| Кровь | Ранение, свежесть | Декаль, блеск = свежая |
| Царапины на коре | Территория, размер | Декаль на стволе |
| Кости и туши | Охотник, давность | Модель; падальщики = свежая |
| Звук | Вид, расстояние, направление | Позиционный звук |
| Тишина | Рядом хищник | Слой насекомых выключается |

**Сканер** — это не «детективное зрение», которое подсвечивает всё вокруг.
Игрок наводит планшет, и сканер уточняет то, что уже в прицеле: вид, свежесть
в часах, направление. Внимательный игрок читает следы и без сканера — по
глубине, блеску и мухам.

**Тропа.** Три прочитанных следа одного животного соединяются на карте
планшета в пунктир с направлением. Карта не показывает животное — только куда
оно шло.

**Тишина насекомых.** Сквозная механика всей игры. Когда в радиусе ~40 м
появляется крупный хищник, слой звука насекомых затихает за 2 секунды. После
Акта II это самый надёжный сигнал опасности — и в Акте VII (территория T-Rex)
насекомые молчат почти всегда.

### 2.3. Полевой журнал (FIELD JOURNAL)

Каждый обнаруженный вид получает страницу.

**Как набираются проценты** (для трицератопса; у других видов пропорции те же):

| Источник | Вклад | Пример |
|---|---|---|
| Первое обнаружение | 10% | Увидел в прицеле камеры или сканера |
| Наблюдение 60 секунд без тревоги | 10% | Сидел в укрытии и смотрел |
| Фото хорошего качества | 10% | Оценка кадра ≥ 2 звёзд |
| Следы 4 типов | 20% | 5% за каждый тип |
| Поведения, 5 штук | 30% | 6% за каждое (сфотографированное или увиденное) |
| ДНК | 20% | `VERIFIED` |

**Что открывается:**

| Порог | Открывается |
|---|---|
| 25% | Имя вида, силуэт, эпоха |
| 50% | Восприятие: дальность зрения и слуха, чувствительность к запаху |
| 75% | Поведенческая подсказка — слабость вида («Рапторы проверяют повторяющийся шум вдвое осторожнее») |
| 100% | Архивная запись Варна о виде — кусочек лора |

Журнал ведёт Итан, но комментирует Лена: у каждой страницы есть её заметки на
полях. Через них раскрывается её персонаж.

### 2.4. Фотокамера

- Режим от первого лица: зум, фокус, выдержка (длинная выдержка ночью смазывает
  движение).
- **Оценка кадра** (1–3 звезды): объект целиком в кадре, резкость, поведение,
  редкость, композиция по правилу третей.
- **Редкие поведения** дают уникальные записи в журнал:

| Вид | Редкие поведения |
|---|---|
| Triceratops | Поединок самцов · кольцо вокруг детёнышей · валяние в грязи · сон стоя · Старуха ведёт стадо |
| Velociraptor | Координированная охота · игра молодых · чистка перьев · «разговор» щелчками |
| Spinosaurus | Рыбалка у порогов · сушка паруса на солнце · бросок из-под воды |
| Pteranodon | Пикирование за рыбой · кормление птенца · брачный показ гребня |
| T-Rex | Рёв на рассвете · поедание туши · сон · Королева с детёнышем (только в одной концовке) |
| Brachiosaurus | Питьё на закате · «арка шей» при опасности |

- **Именные особи.** Фото индивидуально узнаваемой особи (Старуха со сломанным
  рогом, Харон со шрамом на парусе) добавляет её в раздел журнала
  «Знакомые». Это делает экосистему запоминающейся.

### 2.5. Динамическая экосистема

**Потребности.** Каждое животное — набор потребностей: голод, жажда, отдых,
безопасность, общение, размножение. Поведение выбирает utility AI — побеждает
действие, которое сильнее всего снижает самую острую потребность.

**Расписания.** Потребности смещаются по времени суток. Травоядные на рассвете
идут к воде, днём едят, в жару отдыхают в тени. Рапторы и троодоны охотятся в
сумерках и ночью. T-Rex патрулирует на рассвете и после бури.

**Территории и маршруты.** Остров размечен графом: водопои, пастбища, лёжки,
гнёзда, охотничьи угодья, маршруты миграции. Животные перемещаются по графу, а
в пределах узла — по навмешу.

**Взаимодействия видов:**

| Кто | С кем | Что происходит |
|---|---|---|
| Хищник | Травоядное | Охота: выслеживание → бросок → погоня → итог (успех ~30%) |
| Травоядное | Хищник | Сигнал тревоги (паразауролоф трубит) → стадо бежит или встаёт в кольцо |
| Хищник | Хищник | Спор за тушу: угрозы, иногда драка, чаще отступление меньшего |
| Падальщики (компсогнаты) | Туша | Собираются за 5–10 минут, привлекают более крупных |
| Любой | Игрок | Зависит от вида, голода, детёнышей рядом, прошлых встреч |

**Уровни детализации ИИ** — главное условие производительности:

| Уровень | Дистанция | Что симулируется |
|---|---|---|
| L0 | < 80 м | Полный ИИ: восприятие, навмеш, анимация, IK лап |
| L1 | 80–300 м | Упрощённое решение раз в 0,5 с, анимация без IK, без восприятия игрока |
| L2 | > 300 м или вне региона | Только позиция на графе, потребности тикают раз в 10 с |

Лимит: не больше 12 животных на L0 и 40 на L1 одновременно. Стадо на L1 и L2 —
один агент-«стадо», на L0 оно распадается на особей.

**Режиссёр экосистемы.** Следит за «скукой» игрока: сколько времени назад он
видел интересное событие. Если давно, режиссёр подталкивает ближайшую
подходящую сцену: разворачивает миграцию к игроку, повышает голод хищника
рядом с травоядными. Он никогда не создаёт животных в поле зрения.

**Несценарные WOW-моменты** (идея №7) — это события режиссёра с одним
условием запуска, а не кат-сцены:

| Событие | Условие | Что происходит |
|---|---|---|
| «Движущийся лес» | Игрок в джунглях у маршрута брахиозавров, прошло > 15 мин без встречи | Деревья качаются, трещат ветки, насекомые **не** замолкают (подсказка: не хищник). Выходит брахиозавр и проходит мимо |
| «Бегство» | Игрок на равнине, рядом охотящийся хищник | Десятки травоядных проносятся мимо. Через 10–20 с из леса выходит причина |
| «Водопой» | Закат, игрок у реки | Разные виды пьют рядом, соблюдая дистанцию |
| «Падальщики» | Туша не старше часа | Компсогнаты, затем более крупный хищник |
| «Глаза» | Ночь, фонарь включён | Отблески глаз троодонов на краю луча; они уходят, если идти на них |

### 2.6. Восприятие и скрытность

Динозавры замечают игрока тремя чувствами. Сила каждого зависит от вида (она
видна в журнале с 50%).

**Зрение** — конус. Дальность умножается на освещённость, туман и движение:
неподвижного игрока видно вдвое хуже. Укрытия — высокая растительность,
темнота, вода по грудь.

**Слух** — каждое действие игрока создаёт событие шума с радиусом:

| Действие | Радиус шума (стартовые значения для балансировки) |
|---|---|
| Красться | 2 м |
| Идти по папоротникам | 5 м |
| Идти по сухим листьям или гравию | 9 м |
| Бежать | 15 м |
| Идти по мелкой воде | 12 м |
| Упавший предмет, дверь | 15–25 м |
| Шумовая приманка | 30 м |
| Сигнальный пистолет | 40 м + свет |
| Выстрел | 90 м |

Дождь уменьшает все радиусы на 40%, тропический шторм — на 60%.

**Запах** — главная новая механика. У каждого региона есть вектор ветра, и
погода его меняет. Хищник чует игрока, если тот находится **с наветренной
стороны** в пределах дальности нюха. Ветер читается по миру — наклону
папоротников, дыму, пеплу, дождю. UI-стрелка есть только в настройках
доступности. Грязь маскирует запах на 5 минут (Акты IV и VII).

**Тревога.** У животного есть шкала: `спокоен → насторожен → ищет → нашёл`.
Каждое состояние видно и слышно: поднятая голова, фырканье, щелчки, рёв.
UI-индикаторов над головами нет — игрок читает животное, а не иконку.

### 2.7. День, ночь и погода

**Сутки** длятся 48 минут реального времени. Сюжетные сцены могут
зафиксировать время, но между главами оно идёт свободно. В лагере можно
пропустить время до утра или до вечера.

| Время | Что меняется |
|---|---|
| День | Травоядные активны, видимость максимальная, остров «открыточный» |
| Сумерки | Смена смен: травоядные к лёжкам, хищники просыпаются. Самое красивое и самое опасное время |
| Ночь | Видно только в луче фонаря. Троодоны, рапторы, ЕВА-0 в пещерах. Фонарь — выбор: видеть или быть видимым |

| Погода | Игровой эффект |
|---|---|
| SUNNY | Базовые значения |
| RAIN | Слух животных −40%, следы смываются быстрее, течение реки сильнее |
| FOG | Зрение животных и игрока −60%, звуки ближе |
| TROPICAL STORM | Слух −60%, молнии на мгновение подсвечивают всё; травоядные сбиваются в плотные группы, T-Rex выходит на охоту |
| HEAVY WIND | Запах дальше по ветру, в горах порывы сбивают с троп (тайминг-переходы) |

Сюжетная погода зафиксирована: T-Rex всегда появляется в шторм. Всё остальное
время погоду выбирает система, с весами по региону (на болоте чаще туман, в
горах — ветер).

### 2.8. Мобильный лагерь

Лагерь — хаб между вылазками и «дом», который можно потерять.

**Функции:** сохранение · анализ образцов · карта и журнал · подготовка
снаряжения (патроны, фильтры, дротики, приманки) · разговоры с командой ·
пропуск времени.

**Улучшения** из деталей, найденных на острове:

| Модуль | Что даёт | Откуда детали |
|---|---|---|
| Генератор | Ночное освещение, зарядка сканера | Джипы D-01 (Акт III) |
| Мачта ретранслятора | Дальность дрона и связи | Вышки наблюдения |
| Медпункт | Лечение ранений | Медпункт комплекса |
| Верстак | Приманки и дротики | Склады D-04 |
| Проектор журнала | Лена показывает заметки — дополнительные диалоги | Лаборатория комплекса |

**Три лагеря за игру:**

1. «Эхо» — старый передовой лагерь D-04 в долине. Уничтожен в конце Акта IV.
2. Скальный уступ под ретранслятором в горах — временный.
3. Лагерь Линд (D-04) на краю кальдеры — последний, с тяжёлой историей.

**Отношения.** Каждый член команды реагирует на поступки игрока: убийство
животного без необходимости, выстрелы, спасение, доверие. Системы «очков» нет —
только флаги, которые меняют реплики и одну сцену в финале (кто пойдёт с
Итаном к Маяку).

### 2.9. Бой, защита и здоровье

- **Снаряжение игрока:** пистолет (12 патронов на весь акт, пополнение редкое),
  сигнальный пистолет (3 ракеты), 2 шумовые приманки, мачете для зарослей.
- **Сигнальная ракета** — главный «щит»: отпугивает всех, кроме T-Rex и ЕВА-0,
  на 8–15 секунд. Ночью она ещё и приманка для всего живого в радиусе 150 м.
- **Мелкие угрозы** (компсогнаты, одиночный троодон) — ограниченный бой:
  пинок, удар мачете, выстрел.
- **Рапторы** выдерживают 3–4 попадания и отступают раненными — и запоминают.
- **Крупные** не имеют здоровья, только реакцию: отступить или разозлиться.
- **Здоровье** — биомонитор на запястье, без регенерации. Ранения требуют
  перевязки. **Кровотечение пахнет**: пока игрок не перевязан, хищники чуют
  его вдвое дальше.

### 2.10. Перемещение

- Лазание только по читаемым уступам: светлый мох, потёртая порода, скобы
  Варна. Никакой белой краски.
- Балансировка на брёвнах и балках.
- Спуск по верёвке с Акта V.
- Плавание опасно: медленное, шумное, дейнозухи.
- Лодка D-04 на реке: мотор громкий, вёсла тихие.

### 2.11. Прогрессия инструментов

| Акт | Инструмент | Что открывает |
|---|---|---|
| Пролог | Пистолет, сигнальный пистолет, фонарь, биомонитор | — |
| I | Полевая камера | Фото, журнал |
| II | Сканер, набор для образцов | Следы, ДНК |
| III | Шумовые приманки, ключ-карта комплекса | Отвлечение, щитки |
| IV | Биопсийный арбалет, лодка | Дальние образцы, река |
| V | Альпинистский набор | Спуски, вертикальные короткие пути |
| VI | Противогаз, усиленный фонарь | Вулкан, глубокие пещеры |
| VII | Карта доступа Варна | Объект-0 |

Старые регионы с новыми инструментами открывают секреты — лёгкая
Metroidvania-структура для тех, кто хочет 100% журнала.

### 2.12. Интерфейс

- **Минимальный HUD.** По умолчанию на экране ничего нет. Здоровье — на
  биомониторе, ДНК — на кейсе, цель — на планшете.
- **Цель появляется на 4 секунды**, когда меняется (`COLLECT DNA SAMPLES 0/5`),
  затем уходит.
- **Планшет** (кнопка Tab): карта, журнал, фото, записи, цель.
- **Субтитры звуков** — обязательная часть геймплея, раз игра построена на
  звуке: `[тяжёлые шаги — слева]`, `[насекомые замолкли]`.
- **Доступность:** визуальный индикатор направления звуков, стрелка ветра,
  упрощённая скрытность, пропуск QTE, отключение тряски камеры.

### 2.13. Звук как геймплей

Правило: **звук приходит раньше картинки.** Игрок слышит динозавра до того,
как видит.

- Трёхслойная музыка: эмбиент → напряжение → опасность. Слои переключаются по
  состоянию тревоги ближайшего хищника.
- **Тишина — это инструмент.** В ключевых моментах музыка выключается целиком
  (стакан воды перед T-Rex, вход в лагерь D-04, первый вид ЕВА-0).
- Окклюзия звука стенами и листвой, эхо в пещерах и комплексе.
- Инфразвук T-Rex: низкий гул, который ощущается сабвуфером и вибрацией
  геймпада раньше, чем становится слышен.
- Рекомендуется **FMOD** или **Wwise**: динамическая музыка и параметры
  окклюзии в них делаются намного проще, чем на встроенном аудио Unity.
