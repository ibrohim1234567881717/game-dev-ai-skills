# 4. Карта острова и прогрессия

## Принцип

Умбра — не одна огромная пустая карта, а **сеть регионов**, связанных
естественными переходами: ущельями, туннелями, реками, дверями. Каждый переход
одновременно служит границей потоковой загрузки.

Порядок первого прохождения задан сюжетом и инструментами. После Акта VI
пещеры соединяют регионы короткими путями, и остров можно исследовать
свободно — доделать журнал, найти секреты, вернуться за шестым образцом.


Путь первого прохождения:

```
01 → 02 → 03 → 04 → 05 → (ночь: атака на лагерь в 01) → 06 → 07
   → 08 → 09 → 10 → 11 → 12 → 12 (Маяк)
```

## Переходы и потоковая загрузка

| Переход | Тип | Что прячет загрузку |
|---|---|---|
| База → остров | Перелёт на вертолёте, 4–5 минут | Весь остров грузится в полёте — поэтому загрузочного экрана нет |
| 01 → 02 | Узкая тропа в лесу, поворот на 90° | Растительность перекрывает обзор |
| 02 → 03 | Ворота комплекса, заклинившие наполовину | Анимация протискивания |
| 03 → 04 | Затопленный подвальный туннель | Вода, темнота |
| 04 → 05 | Болото редеет, туман расходится | Туман |
| 05 → 06 | Каменная лестница Варна вдоль водопада | Подъём |
| 06 → 07 | Подвесной мост в облаке | Облако |
| 07 → 08 | Спуск-побег по осыпи | Кат-сцена класса B |
| 08 → 09 | Лавовая трубка | Темнота |
| 09 → 10 | Шахта с лестницей наверх | Подъём |
| 10 → 11 | Перевал через край кальдеры | Рельеф |
| 11 → 12 | Периметр Объекта-0, створ ворот | Шторм, дождь |

## Точки интереса

Правило: у каждой точки есть **причина существовать** и **награда**. Ни одной
точки «для заполнения карты».

| Точка | Где | Почему она здесь | Что даёт |
|---|---|---|---|
| Вышки наблюдения T-1…T-4 | 01, 02, 04, 11 | Варн следил с них за миграциями | Обзор, открытие карты, деталь для мачты лагеря |
| Станции отбора S-1…S-5 | По одной у каждого ключевого вида | Автоматические биопсийные кормушки Варна | Лор; S-5 работает и используется в главе T-Rex |
| Джипы D-01 | 02 | Экспедиция 2001 года бросила их при отступлении к комплексу | Детали генератора, жетон с датой, ключ-карта K-4 |
| Обломки вертолёта D-02 | 06 | Разбился в 2006 году, пройдя Вуаль | Бортовой самописец (зацепка про Вуаль), аптечка |
| Палатки D-04 | 01, 05 | Передовые лагеря 2017 года | Аудиодневники Мары, дротики для арбалета |
| Бункеры ORIGO-2017 | 08 | Устья скважин «Пепла» | Запертые, с маркировкой ORIGO — зацепка. Открываются в Акте VIII |
| Станция кернов | 08 | Варн измерял рост острова | «Порода младше Хальма» |
| Подземный сад Варна | 09 | Первый питомник меловой флоры | Самое красивое место игры, светящиеся растения, лор |
| Убежище Мары | 09 (глубокий ярус) | Мара жила здесь с 2017 по 2019 год | Шестой образец, последняя запись, путь к истинной концовке |
| Водопад с пещерой | 01 | Естественный вход в пещерную сеть | Короткий путь, открывается усиленным фонарём |
| Брод миграции | 05 | Стада переходят реку на закате | Редкие фото, WOW-момент |
| Радиомачты | 06, 11 | Старая сеть связи Варна | Связь с базой. **На мачте в 06 можно подслушать приватный звонок Хальма** — ранняя зацепка для внимательных |
| Разрушенные мосты | 06, 02 | Время и Вуаль | Вертикальные пазлы |
| Запечатанные контейнеры | Везде | Грузовые сбросы ORIGO для D-04 | Ресурсы: патроны, фильтры, приманки |

| Гнёзда | 01 (компсогнаты), 07, 11 | Места размножения | Фото редких поведений |

## Прогрессия и гейты

```
Инструмент        Открывает сразу              Открывает при возвращении
────────────────  ───────────────────────────  ─────────────────────────────────
Сканер (II)       Следы, ДНК                   —
Ключ-карта (III)  Комплекс K-4                 Тайная комната Варна в K-4
Арбалет (IV)      ДНК спинозавра               Биопсия других видов → +20% журнала
Альпинизм (V)     Горы                         Короткие спуски в 02 и 05
Противогаз (VI)   Вулкан                       Газовые пещеры, скрытая комната в 04
Фонарь+ (VI)      Глубокие пещеры              Водопад в 01, убежище Мары
Карта Варна (VII) Объект-0                     Тайная комната в 12
```

**Точка невозврата** — вход в Ковчег в Акте VIII. Перед ней игра явно
предупреждает: «После этого пути назад не будет». Шестой образец нужно взять
раньше.

## Ощущение масштаба

Остров должен казаться огромным, даже если играбельная часть компактная.

- **Видимые ориентиры с любой точки:** вулкан (север), Маяк (восток, светится
  ночью), водопад (юг), горный хребет.
- Всё, что видно на горизонте, можно достичь, но позже. «Видишь ту гору? Ты там
  будешь».
- Горизонт — дальние ландшафты с импостерами и HLOD, а не играбельная
  геометрия.
