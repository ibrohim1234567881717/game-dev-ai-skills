# UMBRA — браузерная версия

Играбельная 3D-версия [дизайн-документа](../README.md) в браузере: весь сюжет.
Первое прохождение занимает 60–90 минут, повторное — 35–45 (оценка по коду, живым
игроком не засекалась: озвучка ≈ 18 мин, кат-сцены ≈ 7 мин, остальное — ходьба и
задачи глав). Модели процедурные: тела животных
вылеплены в коде по сечениям, тираннозавр и спинозавр — модели автора из Meshy со
скелетом. Готовые модели из Blender подключаются через реестр персонажей и не
требуют правки логики. Что изменилось в версии 2.0 —
в [TASKS_GAME_2_0.md](../TASKS_GAME_2_0.md).

## Что есть в игре

| Глава | Что происходит | Главная механика |
|---|---|---|
| Пролог «Порог» | База ORIGO, брифинг, кейс с шестым гнездом | Прогулка, диалог, зацепки |
| I «Долина» | Полёт сквозь Вуаль, вид на остров, трицератопсы | Следы, наблюдение, фото, поединок самцов, кровь |
| II «Красный свет» | Комплекс K-4, рапторы | Распределение питания, приманки, бронедверь |
| III «Тёмная вода» | Болото и река, Харон | Чтение воды, биопсийный арбалет, дротик на порогах |
| Интерлюдия | Ночная атака на лагерь | Кат-сцена |
| IV «Высота» | Горная тропа и колония | Порывы ветра, часовые, птенец, пикирующие птеранодоны |
| V «Лагерь Линд» | Вулкан, пещеры, ЕВА-0, лагерь D-04 | Газ, стелс по звуку капели, расследование из 8 улик, шестой образец |
| VI «Королева» | Территория T-Rex, Объект-0 | Ветер и запах, сцена со стаканом воды, станция S-5 |

### Помощь игроку

Здоровье — три сердца. После удара полторы секунды ничто не может ударить снова.
Рапторы в K-4 не нападают в ту же секунду, когда увидели игрока: сначала
замирают и смотрят (≈1,2 с, у самых ног — 0,3 с), и бегущий игрок
(6,6 м/с) отрывается от охотящегося раптора (5,2 м/с). После каждого поражения
в K-4 они видят чуть ближе и дольше присматриваются (до трёх раз).
Если бронедверь не закрыта клавишей за время замедления, она закрывается сама.

## Управление

- **Клавиатура и мышь:** `WASD` идти, мышь смотреть (клик — захват курсора),
  `Shift` бежать, `C` присесть, `E` действие (удерживать, где просит),
  `F` камера, `Q` приманка или арбалет, `Tab` текущая цель, `J` журнал,
  `Esc` пауза, `M` звук.
- **Телефон:** левый палец — джойстик (до упора — бег), правый палец —
  камера, кнопки справа.

Если игрок долго стоит или ушёл не туда, напарник подсказывает направление.
Если это не помогло, появляется маленький маркер с расстоянием до цели.

## Меню

Игра открывается титульным экраном («Нажмите любую клавишу»). Первое нажатие
включает звук: браузер не даёт играть звук до действия игрока. Дальше идёт
главное меню на фоне облёта долины, с музыкой. Пункты меню:

- **Продолжить** — последняя глава с начала, карточка сохранения справа
  (глава, образцы, время сохранения);
- **Новая игра** — спрашивает подтверждение, если есть прогресс;
- **Главы** — любая открытая глава, закрытые показаны без спойлеров;
- **Полевой журнал** — если в нём уже что-то есть;
- **Настройки**;
- **Авторы** — титры, их список в `CREDITS` в `88-menu.js`.

Меню управляется клавиатурой (`↑↓` или `W S`, `Enter`, `Esc`; в настройках
`←→` меняет значение, `Q`/`E` — вкладки, `R` — сброс), мышью и касанием.
Пауза (`Esc`) сделана так же. Мир за ней приглушается, реплика замирает на
полуслове и продолжается после паузы. В паузе видна текущая цель и образцы
в кейсе. Оттуда можно открыть журнал и настройки, вернуться к контрольной
точке или выйти в главное меню.

Настройки:

| Вкладка | Что есть |
|---|---|
| Графика | Качество (Низкое / Среднее / Высокое / Ультра), яркость с калибровкой, поле зрения, тряска камеры, полноэкранный режим, счётчик кадров |
| Звук | Общая громкость, музыка, голоса, эффекты, окружение; озвучка вкл/выкл |
| Управление | Чувствительность мыши или обзора, инверсия оси Y, список клавиш |
| Интерфейс | Субтитры, их размер и фон (с живым примером), обучающие подсказки, маркер цели |

Качество графики меняет тени и пост-обработку сразу, а плотность
растительности — со следующей загрузки главы. Если кадр долго держится ниже
~28 к/с, игра один раз сама снижает уровень, но только пока игрок не выбрал
качество вручную.

Прогресс по главам, пройденные подсказки, настройки (`umbra.settings.v1`) и
уровень графики (`umbra.gfx`) сохраняются в браузере (`localStorage`). Игра
сохраняется в начале каждой главы, это показывает значок «Сохранено» справа
внизу. Если хранилище недоступно, игра работает, но начинается заново.

## Сборка

Исходники лежат в `src/`: `page.html`, `style.css` и JS-файлы, которые
склеиваются в один модуль по порядку имён. Сборка — одна команда, без
зависимостей:

```bash
python games/expedition-d05/web/build.py
```

Результат — `dist/umbra.html`. three.js 0.160.0 подгружается с jsDelivr,
остальное встроено в файл.

Озвучка встраивается, если есть `voice/audio/manifest.json`. Без него или
с `--no-voice` игра показывает только субтитры. Как сгенерировать голоса
через Qwen3-TTS — в [voice/README.md](voice/README.md).

Музыка: файлы из `music/` с именами треков (`menu.mp3`, `danger.mp3`…)
копируются в `dist/music/`, и игра включает их в нужных местах. Если трека нет,
на его месте звучит синтезированная партитура. Список треков, требования и
промпты для генератора — в [music/README.md](music/README.md). Папка
`dist/music/` должна лежать рядом с `umbra.html`.

Королева (T-Rex) — модель автора из Meshy со скелетом. `models/prepare_rex.py`
уменьшает её с 57 МБ до 1,2 МБ (текстуры 1024 px, четыре кости на вершину) и
пишет `models/rex.json`, который сборка встраивает в страницу. Движения —
шаг, бег, рык, принюхивание, поворот головы, хвост, дыхание — сделаны кодом по
костям (`src/24-rex-model.js`), готовых анимаций у модели нет. Без
`models/rex.json` (или с `--no-models`) игра строит прежнюю процедурную
Королеву.

Харон (спинозавр) — тоже модель автора из Meshy (`assets/meshy/spinosaurus.glb`,
87 костей, 10 тыс. треугольников). Тот же скрипт с аргументом —
`models/prepare_rex.py spinosaurus` — пишет `models/spino.json` (1,4 МБ), а
`src/24-spino-model.js` двигает её кости: шаг, хвост-плавник, бросок шеи,
челюсть, подъём головы у водосброса. Парус — часть меша на позвонках. Без
`models/spino.json` игра строит прежнего процедурного спинозавра. Новая модель
встаёт в те же места: глава «Река» (точка укуса берётся из модели) и запись
D-04 в брифинге.

Как добавить ещё одну модель Meshy (GLB со Smart Rig, без анимаций):
положить её в `assets/meshy/`, добавить строку в `MODELS` в
`models/prepare_rex.py` и встраивание в `build.py`, затем по образцу
`24-spino-model.js` выписать роли костей (имена у Meshy — `Bone_000…`, их
приходится узнавать по иерархии и по тому, какие вершины за какой костью
идут) и вызвать новую модель из функции вида в `25-creatures.js` с запасным
процедурным вариантом.

Для Яндекс Игр — отдельная сборка, где ничего не грузится снаружи, а SDK
платформы подключён:

```bash
python games/expedition-d05/web/build.py --target yandex
```

Она пишет `dist/umbra-yandex.zip` для загрузки в консоль. Как её загрузить и
что проверить перед модерацией — в [YANDEX.md](YANDEX.md).
